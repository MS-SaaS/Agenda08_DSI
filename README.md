## Agenda 08 - Desenvolvimento de Sistemas

Nessa agenda, tive a tarefa de criar um programa que utilizasse estruturas de repetição para obter diversos tipos de informações diferentes.

Acho que nunca tinha usado esse tipo de sistema antes, então tive que dar uma pesquisadinha antes de concluir essa tarefa. Porém, gostei de realizar essa atividade.

O programa se encontra no arquivo dentro dessa mesma pasta e pode ser utilizado de forma simples, inserindo o nome, a idade e o número correspondente ao nível de satisfação.
